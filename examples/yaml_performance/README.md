# Performance Analysis Example

This example demonstrates the performance measurement and optimization utilities for YAML processing.

## Features Demonstrated

1. **DocumentStats** - Analyze document structure and memory usage
2. **Timer** - Measure single operation duration
3. **Profiler** - Track multiple operations with aggregate statistics
4. **compare_performance** - Side-by-side performance comparison

## Usage

```bash
cargo run --example yaml_performance
```

## What You'll Learn

- How to gather comprehensive statistics about YAML documents
- Memory estimation for parsed documents
- Timing individual operations
- Profiling multi-step workflows
- Comparing different approaches for performance optimization

## Real-World Applications

- **Capacity Planning** - Estimate memory requirements for large documents
- **Performance Tuning** - Identify bottlenecks in processing pipelines
- **Benchmarking** - Compare different YAML processing strategies
- **Monitoring** - Track performance metrics in production
